[FOAIDE](https://github.com/haothtrteen/FOAIDE)（Flutter on Android IDE）想验证一件事：**不带电脑，能不能把 Flutter 应用从写代码一路做到装到手机上。**

结论是可以。它不需要 root，也不需要外接设备。

## 为什么这件事本来做不到

官方 Flutter **不支持在 Android 上构建 Android 应用**。FOA 用三层把它拼出来：

| 层 | 做法 | 为什么需要 |
|---|---|---|
| 容器 | proot + Debian rootfs（免 root） | 在 Android 上跑完整 Linux 工具链，且不动系统 |
| 工具链 | 设备内安装 Flutter SDK / Android SDK / JDK | 不依赖电脑，全部落在容器里 |
| 指令翻译 | QEMU 跑 x64 版 `gen_snapshot` / `impellerc` | 官方**没有** arm64 版 AOT 工具 |

第三层是真正的难点：Flutter 的 AOT 编译器只提供 x64 版本，arm64 设备上必须靠 QEMU 做指令翻译才能跑通构建。项目开发手册里绝大部分 bug 都来自这一层。

整体结构：

```
Android 设备（arm64，无 root）
  FOA App（Flutter）
    ├─ 代码编辑器 / 设计器 / 清单编辑
    ├─ Web 热重载预览（改代码即时看效果）
    └─ 构建编排 ──┐
                  │ fork/exec
  ┌───────────────▼────────────────────────┐
  │  proot 容器（Debian bookworm arm64）   │
  │    ├─ Flutter SDK / Dart               │
  │    ├─ Android SDK / Gradle             │
  │    └─ 你的工程 → 产出 APK              │
  └────────────────────────────────────────┘
```

## 功能

| 区域 | 能力 |
|---|---|
| 工程 | 新建空白模板、导入 zip/tar.gz/tar.xz、导出 tar.gz、git 远端（HTTPS + PAT，只走 `--ff-only`） |
| 编辑 | 语法高亮、自动保存、外部改动自动同步 |
| 设计 | 可视化界面设计器生成 Flutter 代码，也能从已有 UI 反向导入 |
| 清单 | 应用名 / 包名 / 版本 / 权限 / 混淆开关 / 图标替换 / 签名补丁 |
| 构建 | debug（JIT，快）与 release（AOT，可上架）双模式，实时日志，失败自动分诊 |
| 工具链 | 一键安装 Flutter SDK / Android SDK / JDK / x64 兼容层 |
| AI | 内置 LLM 接入（OpenAI 兼容接口）与 MCP 客户端，可把任务派给远端 AI |

## 上手前要知道的

- 需要一台 **arm64 Android 设备**，Android 10 以上，不需要 root
- 预留约 **8 GB 存储**（SDK + rootfs + 构建缓存）
- 首次要联网下载 SDK，容器内走清华 TUNA 镜像
- 仓库里**不含** 75MB 的 Debian rootfs（体积原因），需要自己用 `debootstrap` 构建一次，或向维护者索取

最快的体验路径：

```bash
git clone https://github.com/haothtrteen/FOAIDE
cd FOAIDE/app
bash tools/fetch_assets.sh     # 下载 proot 等未跟踪资产
flutter pub get
flutter run --release          # 装到设备上
```
