[TweakMe](https://github.com/haothtrteen/TweakMe) 仓库里放的是 TwPatch（TweakMe on Android）——一个**在手机上直接对 APK 做二次打包注入**的工具。

## 它做什么

选一个 APK，工具完成：

1. **重打包**
2. **过签名**（含对主流第三方加固的一定处理能力）
3. **注入 hook 框架 / 插件**
4. 输出可直接安装的新包

用 Java 写 hook 代码，一键脚本编译成 dex 插件注入，对简单的 Xposed 插件也做了兼容。

## 为什么不用 Xposed / Frida

那些框架要么需要 root，要么需要在目标设备常驻服务。TwPatch 的思路更"一次性"：

- 不需要 root，一台正常手机就行
- 对系统版本要求低，5.0 到 13.0 都测过
- 支持 arm 与 arm64
- 成品是独立 APK，装到别的设备上也能用

代价是每次改动都要重新打包，调试循环比动态 hook 长——适合"改完就用"的场景，不适合频繁试错。

## 和原项目的区别

TwPatch 基于开源的 TweakMe 制作，主要工作是把操作**简化到能在安卓上跑**：原项目更依赖桌面端命令行，TwPatch 把大部分步骤自动化成了图形操作。

这个项目从 2023 年就在维护，中间收到很多朋友的测试反馈和 bug 报告，感谢名单都写在仓库 README 里。

## 适用范围

二次打包注入本身是中性技术，可以用来给自己写的应用加调试能力、给老应用补功能、做兼容性适配。**请只对自己拥有或获得授权分析的应用使用**，不要用来修改他人应用的授权校验或分发破解版本。
